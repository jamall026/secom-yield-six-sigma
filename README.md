# Semiconductor Yield Improvement: A Six Sigma DMAIC Project

Improving the yield of a real semiconductor manufacturing process using the Six Sigma DMAIC method (Define, Measure, Analyze, Improve, Control).

**Status:** In progress. Started November 2026.

## The problem

A semiconductor fab records 590 sensor readings for every unit it produces. Of 1,567 units, 104 failed final test. This project finds which process signals are linked to those failures and sets up monitoring to catch problems early.

## Project roadmap

- [x] **Define:** [project charter](docs/1_define/charter.md) and [SIPOC](docs/1_define/sipoc.md)
- [ ] **Measure:** data quality check and baseline yield
- [ ] **Analyze:** identify the signals linked to failures
- [ ] **Improve:** early-warning model and recommendations
- [ ] **Control:** control charts and control plan
